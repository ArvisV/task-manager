#  Task Manager API

Laravel backend API priekš projektu (tasku) pārvaldības.

---

##  Par projektu

Šis ir REST API, kas ļauj:
-  Izveidot projektu
-  Apskatīt visus projektus
-  (drīz) Rediģēt projektus
-  (drīz) Dzēst projektus

---

##  Tehnoloģijas

- PHP (Laravel)
- MySQL
- Postman (API testēšanai)
